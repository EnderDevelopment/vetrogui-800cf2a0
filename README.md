# Vetro GUI for Roblox Pet Spawner

This project includes a sleek black GUI titled 'Vetro' for the pet spawner tab in Roblox, allowing you to spawn pets, size dupe, and give mutations.

## Install

1. Open Roblox Studio and create a new place or open an existing one.
2. In the Explorer, navigate to `StarterGui`.
3. Right-click on `StarterGui` and select `Insert Object` > `ScreenGui`.
4. Name the new ScreenGui `VetroGUI`.
5. Right-click on `VetroGUI` and select `Insert Object` > `LocalScript`.
6. Name the new LocalScript `VetroGUIScript`.
7. Copy the contents of `VetroGUI.lua` and paste it into `VetroGUIScript`.

## Use

1. Open the game in Roblox Studio.
2. Press `F5` to start the game.
3. The Vetro GUI will appear on the screen.
4. Use the buttons to spawn pets, size dupe, and give mutations.
